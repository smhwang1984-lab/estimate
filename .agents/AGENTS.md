# Estimate(견적) 에이전트 지침

작업을 시작하기 전에 저장소 루트의 **`HANDOVER.md`(인수인계서)** 를 먼저 읽는다.
프로젝트 구조, 견적 양식(`견적용.xlsx`)의 시트 구조, 절대 하면 안 되는 것(과거에 실제로
문제가 됐던 함정 12가지), 빌드·배포 절차, 검증 방법, 남은 일이 거기에 정리돼 있다.

작업 기록은 버전별 개별 파일을 만들지 말고 **`plan.md` 하나에 통합**해서 이어 적는다
(`plan.md`는 BOM 있는 UTF-8 + CRLF이므로 전체 재작성 대신 append 한다).

# 기본 작업 원칙

- 사전에 요청에 관련성 있는 파일들만 검토를 깊이 있게 점검 한다.
- 코드, 문서, 버전, 배포 파일을 변경하기 전에는 먼저 작업 계획을 작성한다.
- 사용자 승인 전에는 구현, 버전 변경, 빌드, ZIP 생성, 서버 배포를 하지 않는다.
- 사용자가 “승인”이라고 명시한 뒤에만 구현을 시작한다.
- 수정 완료 후에는 변경 내용, 검증 결과, 배포 파일 위치를 간결하게 보고한다.
- 불확실한 요구사항은 구현 전에 질문한다.
